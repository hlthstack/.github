# hlthstack

Health benefits for your members, through one API: annual health checkups and lab tests,
in-clinic and online doctor consultations, ePharmacy, benefit wallets and member
onboarding, with status updates by webhook.

## Start here

- **[Getting started](https://github.com/hlthstack/integration-guide/blob/main/docs/getting-started.md)**: from access request to go-live.
- **[API reference](https://developers.hlthstack.io)**, and the [Postman docs](https://documenter.getpostman.com/view/32733686/2sBYHbrFjt) to try every call.
- **[Integration guide](https://github.com/hlthstack/integration-guide)**: OpenAPI spec, guides, changelog, and skills for Claude Code, Codex and ChatGPT.

## SDKs and embeds

| | Install |
|---|---|
| [JavaScript / TypeScript](https://github.com/hlthstack/js) | `npm install github:hlthstack/js#v1.0.1` |
| [Python](https://github.com/hlthstack/python) | `pip install "git+https://github.com/hlthstack/python@v1.0.1"` |
| [Java](https://github.com/hlthstack/java) | JitPack: `com.github.hlthstack:java:v1.0.1` |
| [Web / PWA embed](https://github.com/hlthstack/web) | Embed the member app in your app or site, with SSO or SAML |
