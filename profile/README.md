# hlthstack

**Health benefits for your members, through one API.**

Annual health checkups and lab tests, in-clinic and online doctor consultations, ePharmacy,
benefit wallets and member onboarding, with status updates by webhook.

[For business teams](https://github.com/hlthstack/integration-guide/blob/main/docs/for-business-teams.md) ·
[Getting started](https://github.com/hlthstack/integration-guide/blob/main/docs/getting-started.md) ·
[API reference](https://developers.hlthstack.io) ·
[Postman docs](https://documenter.getpostman.com/view/32733686/2sBYHbrFjt) ·
[Integration guide](https://github.com/hlthstack/integration-guide) ·
[Request access](https://www.hlthstack.io/)

## What you can build

| For your members | With |
|---|---|
| Book annual health checkups and lab tests | The REST API |
| Book in-clinic and online doctor consultations | The REST API |
| Order medicines (ePharmacy) | The REST API |
| Show benefit wallets | The REST API |
| Onboard members | The REST API |
| Receive status updates | Webhooks |
| Offer the whole member app inside your app or site, with SSO or SAML | The [Web / PWA embed](https://github.com/hlthstack/web) |

## SDKs and embeds

| | Install |
|---|---|
| [JavaScript / TypeScript](https://github.com/hlthstack/js) | `npm install github:hlthstack/js#v1.0.2` |
| [Python](https://github.com/hlthstack/python) | `pip install "git+https://github.com/hlthstack/python@v1.0.2"` |
| [Java](https://github.com/hlthstack/java) | JitPack: `com.github.hlthstack:java:v1.0.2` |
| [Web / PWA embed](https://github.com/hlthstack/web) | Embed the member app in your app or site, with SSO or SAML |
